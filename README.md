# Hamyol — помощник в поездке (Узбекистан · Азербайджан · Мекка и Медина)

**Hamyol** (раньше — Safar) — приложение для путешественников. Три приложения на одном сервере:

| Приложение | Адрес | Для кого |
|---|---|---|
| **Азербайджан** | `/az` | Взрослые и пожилые: крупные кнопки, переводчик, транспорт, такси, всё работает без интернета. Открывается первым |
| **Узбекистан** | `/` | Туристы: города, отели, места, карта, навигация, цены, план поездки, гиды. 8 языков |
| **Мекка и Медина** | `/mecca` | Паломники: святыни, отели у Харама, намаз, «Я потерялся» |

Переключиться между ними можно в аккаунте каждого приложения.

Один и тот же код работает тремя способами:

- **сайт и PWA** — открывается в браузере, ставится на экран «Домой» (iPhone и Android);
- **Android-приложение (APK)** — собирается из сайта одной командой;
- **Telegram Mini App** — открывается из бота, вход без пароля.

Языки интерфейса: O‘zbekcha, Ўзбекча, Русский, English, Türkçe, Deutsch, 中文, 한국어.

## Состояние проекта

*Итоговая проверка — 16 октября 2026. В тот же день добавлены статистика, метки источников и опрос — чтобы тест на людях давал цифры.*

**Готово к тесту на людях.** Все функции из плана, которые не требуют денег, договоров или живых данных, сделаны и проверены. Дальше — запуск, отзывы первых пользователей и правки по ним.

| | |
|---|---|
| Размер | 57 файлов интерфейса (~10 400 строк), 29 модулей сервера (~3 200 строк), CSS ~3 100 строк. 72 адреса API, 29 таблиц в базе. Одна рабочая зависимость (`@anthropic-ai/sdk`) |
| Данные | 349 городов и посёлков, 9 132 места, ~11 000 полезных объектов, 8 языков (~990 строк перевода на каждом) |

**Что проверено в итоговом анализе**

- **Код:** синтаксис всех файлов в `js/` и `server/`; каждый скрипт из `index.html` есть в кэше `sw.js`; все файлы из кэша существуют.
- **Переводы:** все ключи, которые использует код, есть на всех 8 языках (кроме внутренних строк админки и SEO — у них uz, ru, en).
- **Сервер на чистой базе:** главные страницы, `/health`, `sitemap.xml`, SEO-страницы, API отвечают правильно; `/api/me` без входа — 401; админка выключена — 404.
- **Безопасность:** `.env`, `storage/safar.db`, ключи подписи и исходники сервера недоступны снаружи, в том числе через `..`, `%2e%2e` и `%5c` (обход путей в Windows). Все запросы с записью ограничены по размеру, а публичные — по частоте. Токен админки сравнивается защищённо от подбора по времени.
- **Интерфейс:** 27 разделов на компьютере и 18 разделов на ширине телефона 375 px в светлой и тёмной теме — ни одной ошибки JavaScript, страница нигде не шире экрана (широкие только ленты карточек, они листаются).
- **Новые функции** («Когда людно», «Поездка с друзьями», праздники в боте) проверены тестами на временной базе и в браузере.

**Известные ограничения — честно**

| Что | Почему | Что делать |
|---|---|---|
| Данные мест из OpenStreetMap местами устарели или странные (например, «Ташкент-Наманган» записан как достопримечательность) | Это открытые данные, их правят волонтёры | Проверить вручную главное в Ташкенте, Самарканде, Бухаре и Хиве; туристы помогут через «Сообщить об ошибке» |
| Карта, маршруты и погода — на бесплатных общественных сервисах | У них ограничения по нагрузке и по коммерческому использованию | См. [«Запуск без денег и бюджет»](#запуск-без-денег-и-бюджет) |
| «Когда людно» пуст, пока у места нет 10 отметок | Показываем только реальные данные | Просить первых туристов нажимать «Я здесь» |
| В «Поездке с друзьями» менять план может любой, у кого есть ссылка | Так проще: вход не нужен | Не публиковать ссылку открыто |
| Даты хайитов и Рамадана примерные, только на 2026–2028 | Зависят от луны | В 2028 году дописать следующие годы в `js/holidays.js` и `server/botremind.js` |
| Онлайн-оплаты нет | Нужен договор с Payme, Click или Uzum | Пока «оплата гиду при встрече» |
| Нет автоматических тестов | Проверки делались вручную и скриптами | Перед большими изменениями — проверки из раздела [«Как продолжать работу»](#как-продолжать-работу) |
| Один процесс Node и SQLite | Для старта это быстрее и проще | Хватит на тысячи пользователей в день; дальше — думать о масштабировании |

## Что умеет

### Путешественнику

| Функция | Что делает |
|---|---|
| **Города и места** | 349 городов и посёлков, ~9 000 мест: отели, базары, достопримечательности, рестораны. Фильтры, «Рядом со мной», «Открыто сейчас» по часам работы. Кнопка «Рядом со мной» — переключатель: включена — бирюзовая и сортирует по расстоянию, повторное нажатие возвращает прежнюю сортировку |
| **Карта** | Все места и ~11 000 полезных объектов: банкоматы, обмен, аптеки, больницы, туалеты, АЗС, вокзалы, аэропорты. Место назначения и «это место» на мини-картах — золотая метка-капля своим рисунком (без картинок со сторонних сайтов, работает без интернета). Кнопки масштаба, всплывающие окна и подсказки карты — в цветах темы |
| **Навигация внутри приложения** | Маршрут пешком или на машине, пошаговые подсказки на 8 языках, режим «Поехали»: ведение по карте, голос, перестроение при сходе с маршрута, экран не гаснет |
| **Такси** | Кнопка открывает Yandex Go с уже подставленными точками |
| **План на день** | Для ~130 городов: главные места в кратчайшем порядке, обед рядом. Весь план можно пройти маршрутом |
| **Главная** | Большое фото, поиск и одна главная кнопка «Собрать поездку» (плюс «Карта»); популярные города и готовые маршруты — лентой крупных карточек с фото; «Полезно знать» — плитками; погода, курсы и регионы — одним раскрывающимся блоком внизу |
| **Вкладка «Поездка»** | Новая поездка пустая: подсказка «Куда поедем?» и три способа начать — по бюджету, готовый маршрут, вручную (или кнопками Ташкент / Самарканд / Бухара / Хива). Дальше шаги: 1 Маршрут → 2 Бюджет (настройки свёрнуты в одну строку) → 3 По дням → 4 В дорогу (вкладки «Перед поездкой», «Что взять», «Расходы») |
| **Поездка по дням** | Даты, переезды по реальным дорогам, план осмотра, прогноз погоды на 16 дней, бюджет. Выгрузка в календарь (.ics), печать / PDF, ссылка на поездку |
| **Готовые маршруты** | 8 подборок с оценкой бюджета, загружаются в планировщик одним нажатием |
| **Цены на месте** | Нормальная цена на такси, еду, вход, сувениры и связь в каждом городе. Проверка «не завышают ли», фраза для торга. Путешественники присылают реальные цены, от трёх сообщений показывается медиана |
| **Когда ехать** | Климат по месяцам, лучшие месяцы для поездки |
| **Путеводитель** | Разговорник с произношением, экстренные номера, советы |
| **Когда людно** | На странице места (кроме отелей) — график по часам с 7:00 до 22:00 и «Сейчас обычно: спокойно / средне / людно». Строится только из реальных отметок «Я здесь» (в 300 м от места, раз в день, хранится час и день без данных о человеке) и появляется после 10 отметок |
| **Вопросы и ответы** | У каждого места (как TripAdvisor): «Можно ли с детьми?» — отвечают туристы, владелец места и гиды (с отметкой). Владельцу приходит вопрос в Telegram, автору — ответ. Админка → «Вопросы»: скрыть/показать |
| **Отзывы** | Звёзды, текст, до 3 фото и (у мест, по желанию) оценки по пунктам: чистота, цена/качество, обслуживание, расположение — средние показываются полосками. Фото уменьшаются на телефоне и очищаются от GPS и других данных снимка. У отзыва вошедшего человека (Telegram или Google) — отметка «✓ Проверено» |
| **Без интернета** | Офлайн-набор города: описание, главные места, фото, прогноз, полезные места. Приложение само, в фоне и по одному городу с паузами, сохраняет только то, что нужно этому человеку: города, которые он открывал, города его поездки и ближайший город (последний — только если геолокация уже разрешена и дано согласие; разрешение само не спрашивается). На Wi-Fi — с миниатюрами фото, на мобильном интернете — только тексты и прогноз, при «Экономии трафика» — ничего. Подложка карты заранее не скачивается (правила OpenStreetMap) |
| **Меню «Офлайн»** (`#offline`) | Сохранённые города с размером и датой, кнопка «Удалить» у каждого, ход фонового сохранения, переключатель «Сохранять автоматически» и поиск по всем городам с кнопкой «Скачать». Открывается кнопкой «Офлайн-города» в «Избранном», плиткой на главной и из аккаунта |
| **Недавно смотрели** | Лента последних 8 открытых городов и мест на главной (над «Популярными»), кнопка «Очистить». Хранится на устройстве, работает без сети |
| **Чек-лист сборов** | Во вкладке «Поездка»: паспорт, наличные доллары, карта, закрытая одежда для мечетей и др. + пункты по сезону месяца поездки. Галочки, свои пункты, прогресс «5 из 12» |
| **Возврат сети** | Плашка «Нет интернета — работают сохранённые данные». Связь проверяется запросом к серверу, а не только по сигналу браузера. Когда сеть вернулась — тост «Интернет-соединение восстановлено» и повторная загрузка всего, что не загрузилось: курсы, отзывы, погода и Википедия в текущем разделе и открытом окне, тайлы карт |
| **Поделиться** | Ссылка на город или место ведёт на его публичную страницу (`/city/<id>`, `/place/<id>`) — с названием, описанием и фото в мессенджерах. Через системное окно «Поделиться» или копированием ссылки |
| **Сообщить об ошибке** | У каждого места: неверные часы, закрыто навсегда, неверный телефон или адрес, другое (+ комментарий до 300 символов). Отправляется после согласия, администратор видит во вкладке «Ошибки» |
| **Поездка с друзьями** | Во вкладке «Поездка» — «Пригласить друзей»: ссылка `#together/<код>`, по которой все вместе меняют маршрут, даты, настройки бюджета и делёж расходов. Правки уходят на сервер через секунду, чужие приходят за 15 секунд с подписью «Аня изменила план». Если двое правили одновременно — побеждает первый, второму показывается свежая версия. Вход не нужен (доступ по секретной ссылке), неиспользуемые планы удаляются через 180 дней. «Выйти» оставляет копию плана на устройстве |
| **Делёж расходов** | Во вкладке «Поездка»: участники, траты (кто платил, сколько, на кого делится) в любой валюте и итог «кто кому сколько» с минимумом переводов. Хранится на устройстве |
| **Напоминания** | Push накануне поездки и каждое утро в поездке — с погодой; в боте (`/remind`) — ещё советы по погоде и предупреждение о празднике или Рамадане |
| **ИИ-гид** | Отвечает по данным Safar и предлагает маршрут, который загружается в планировщик (Claude API) |
| **Поезда** | Популярные направления (Afrosiyob, Sharq, обычные) с примерным временем в пути и кнопкой покупки билета на uzrailpass.uz |
| **Безопасно ли?** | Виза и регистрация, деньги, интернет и SIM, такси, вода и еда, советы женщинам, съёмка, экстренные номера |
| **Свайпы** | Листание разделов пальцем (выключается в настройках «Aa»), «Назад» свайпом от левого края — в приложении на iPhone |
| **Отображение («Aa»)** | Размер текста (5 ступеней), шрифт (Montserrat, Nunito, Atkinson Hyperlegible, системный), жирный текст, межстрочный интервал, тема, «меньше движения» |
| **Паспорт путешественника** | Кнопка «Я здесь» на странице города даёт штамп, если вы в пределах 20 км (геолокация с согласием). Медали и задания: первый штамп, столица, Шёлковый путь (и он же за 10 дней), 5 и 10 городов, 3 города за неделю, 30 и 100 открытых мест, 5 базаров, 10 кафе. Хранится только на устройстве (`#passport`) |
| **Общие списки** | «Поделиться списком» в «Избранном» — ссылка `#list/…`: друг видит города и места, сохраняет всё себе или добавляет города в поездку. Список целиком в ссылке, сервер не нужен |
| **Слово дня** | На главной — фраза дня по-узбекски с переводом и кнопкой «Послушать»; в боте — `/word` |
| **Дневник поездки** | Из штампов паспорта (`#diary`): маршрут на карте, города по датам, километры, дни, медали и картинка 1080×1350 «Мой Узбекистан» для соцсетей (рисуется на устройстве) |
| **Праздники и Рамадан** | На странице места — предупреждение, если сегодня праздник или Рамадан; во вкладке «Поездка» — праздники на датах поездки. Даты хайитов и Рамадана примерные (2026–2028) |
| **Чаевые и счёт** | В «Ценах на месте»: сумма счёта, сколько человек, включено ли обслуживание, чаевые 0–15% → сколько платит каждый |
| **Жалобы и предложения** | Блок «Что-то не так? Напишите нам» в самом низу главной и ссылка в аккаунте (`#feedback`): тип обращения, текст, контакт по желанию. Человек получает номер, статус и ответ видны там же; администраторам — уведомление в Telegram, ответ из админки («Обращения») уходит человеку в бот |
| **Страница места** | Крупные кнопки главных действий (как в Google Maps): «Маршрут», «Сохранить», «Позвонить», «Бронь» или «Сайт»; ниже — «На карте», «Поделиться», Google Maps, Яндекс Карты; адрес, телефон, часы и цена — строками с иконками |
| **Быстрые фильтры отелей** | Кнопки над списком, как в Booking: «до 20 / 40 / 70 $» (в валюте приложения), «С отзывами» (когда появятся), «С телефоном»; выбор запоминается |
| **Мои билеты** | Поезд, самолёт, автобус, музей — в одном месте и без интернета (`#tickets`, вкладка «Билеты» в «Поездке»). Добавить: выбрать PDF/фото, «Поделиться → Safar» на Android или переслать файл Telegram-боту — после входа через Telegram билет появится в приложении. Билет открывается на весь экран, экран не гаснет |
| **Экстренная помощь** (`#sos`) | **Красная круглая кнопка SOS посередине нижнего меню** (видна с любого экрана), на компьютере — красная «SOS» в верхней панели; плюс красная плитка первой на главной. Кнопки 103 скорая · 102 полиция · 101 пожарные (звонок — после подтверждения, чтобы случайное касание не вызвало скорую). **«Где я» — точное место**: GPS в режиме высокой точности, без старых сохранённых точек, до 20 секунд уточнения с выбором самого точного измерения (останавливается на ± 15 м); точность показывается («± 9 м — очень точно, до дома»), при низкой — подсказка выйти на открытое место и кнопка «Уточнить». Адрес по-узбекски и по-русски (OpenStreetMap Nominatim): здание, улица и дом, махалля, район, город, область; если найденный адрес дальше 40 м — честно «примерно в N м». Плюс ближайший ориентир, координаты и **Plus Code** (11 знаков ≈ 3 × 3 м, ищется в Google Картах) — что сказать оператору; «Показать крупно» на трёх языках. **«Отправить мою точку»** — сообщение со ссылками Google и Яндекс Карт через «Поделиться», Telegram, WhatsApp, SMS. **Ближайшая помощь** — больницы, клиники, аптеки, АЗС по расстоянию, со звонком и маршрутом. **«Машина сломалась»** — что делать по шагам и кнопка страховой (номер из медкарточки). Службы приложение само не вызывает — такой связи нет; оно помогает быстро позвонить и объяснить, где вы. **Тестовый режим по умолчанию**: всё работает, кроме звонка («ТЕСТ: звонок не совершён»), и есть «Тестовая точка (Регистан)». **Настоящие звонки включены** (`SOS_LIVE=1` в `.env`; тестовые серверы из `.claude/launch.json` всегда запускаются с `SOS_LIVE=0`): тогда вместо тестовой плашки — крупное красное мигающее предупреждение «ВНИМАНИЕ: ЭТО НАСТОЯЩИЙ ЗВОНОК… ложный вызов запрещён законом», а окно подтверждения спрашивает «НАСТОЯЩИЙ звонок: Скорая помощь — 103? Это не тест» с кнопкой «Да, позвонить 103» |
| **Мои документы** (`#docs`) | Копии паспорта, визы, страховки, брони отеля, регистрации: сфотографировать или выбрать файл, указать «действует до» — за 30 дней до конца срока предупреждение, после — «Срок истёк». Открываются на весь экран без интернета, с пометкой «это копия». **Хранятся только на этом телефоне** (IndexedDB `safar-docs`): на сервер не отправляются, в аккаунт не попадают; приложение просит браузер не удалять эти данные. На iPhone советует установить Safar на экран «Домой», чтобы Safari не стёр данные. Плитка в аккаунте и на главной |
| **Медицинская карточка** (`#docs/med`, показать сразу — `#med`) | Имя, дата рождения, группа крови, аллергии, лекарства, болезни, кому звонить, страховка, языки. «Показать врачу» — на весь экран, крупно, подписи сразу на узбекском, русском и английском, телефоны нажимаются, экран не гаснет, внизу номера 103 · 102 · 101. Тоже только на телефоне |
| **Показать таксисту** | У каждого места: на весь экран крупно название и адрес на узбекском и русском, экран не гаснет |
| **Удобство** | Избранное, тёмная тема, режим крупного текста, приветствие при первом запуске. Кнопка «Назад» — на страницах городов, мест и разделов, куда пришли со страницы; на главной её нет никогда. Кнопка «В поездку» на странице города — переключатель «＋ В поездку» ↔ «✓ В поездке» (город не добавляется дважды). Важные действия (выход из аккаунта) — с окном подтверждения |
| **Оформление и доступность** | Проверено на ширине телефона 375 px в светлой и тёмной теме: ничего не выходит за экран, вкладки и чипы не сжимаются, кнопки на сенсорных экранах не ниже 36 px. Текст читается по WCAG: приглушённый, золотой и зелёный («Открыто») текст — контраст от 4,5; кнопка Telegram и подпись карты OpenStreetMap — тоже. **Тема меняет всё**: кнопки «Назад» и «Закрыть» на фото, сердечко «В избранное», поле поиска, элементы карты, выпадающие списки, кнопка Google и фон окна Telegram Mini App; белыми остаются только «бумажные» экраны — QR-постер, печать, «Показать таксисту», билет. **Крупный текст** (130–150 %) проверен на всех разделах: длинные слова переносятся, ничего не обрезается краем экрана. Пока открыта панель «Aa», страница под ней не прокручивается. Окна (город, место, аккаунт) на телефоне непрозрачные: сзади не просвечивает страница, прокрутка не уезжает за край и не передаётся странице. Касание мимо выпадающего меню (язык, валюта) только закрывает его и не нажимает то, что под пальцем. Вкладки («В дорогу», вкладки города) показываются своей анимацией и не остаются прозрачными |

### Азербайджан (`/az`) — простое приложение для взрослых и пожилых

Отдельное приложение: `az.html`, `js/az-*.js`, `css/az.css`, сервер `server/az.js`, `server/az-maps.js`, данные `data/az-*.js`. Свой сервис-воркер `az-sw.js`. Языки интерфейса — русский и английский.

| Функция | Что делает |
|---|---|
| **Простой режим** (по умолчанию) | После проверки на живых людях («путаются, всего слишком много»): на главной 4 большие кнопки — «Поговорить», «Куда ехать», «Такси», «SOS», остальное в «Ещё». Полный режим включается в «Ещё» или в аккаунте (`js/az-simple.js`) |
| **Умный поиск** | «Баку», «Baku», «Bakı» и даже «Ьаку» или «ифлг» (не та раскладка) находят одно и то же: общая латинская основа, опечатки в 1–2 буквы, смена раскладки. Сначала — самые известные места |
| **План поездки** | Для любого города: человек пишет только дни, деньги и сколько вас — приложение само подбирает отель по бюджету, места по дням рядом друг с другом, обед и ужин, дорогу (пешком, транспорт, такси). Кнопка у каждого города (карточки, страница города и места, поиск, «Без интернета», «Ещё»); если план уже есть — «Перейти к своему плану». | **Фото и прогулка по улице** | Фото города или места открывается на весь экран, приближается двумя пальцами. «Прогулка по улице (360°)» — панорамы улиц Google прямо в приложении: осмотреться и пройти вперёд (нужен интернет; встраивание без ключа, неофициальное) (`js/az-view.js`) |
| **«Назад»** | Возвращает на то же место экрана: прокрутка, раскрытые разделы и «Показать ещё» сохраняются |
| **Переводчик** | Русский / узбекский / английский ↔ азербайджанский. **Разговор голосом**: две большие кнопки-микрофона («Говорите» и «Danışın»), кнопка горит и пульсирует, пока слушает, перевод появляется на лету и звучит вслух. **Перевод по фото** (Tesseract.js, азербайджанский и русский словари) — меню, вывески, таблички. **Без интернета**: модели Mozilla (Bergamot, как в Firefox), русский ↔ азербайджанский через английский; словарь частых табличек; готовые фразы и история. Онлайн — Microsoft Translator / Google (ключ в `.env`) или MyMemory |
| **Навигатор** | Свой, без перехода в Google Карты: пешком, на машине, **на транспорте** (метро, автобусы, поезда с пересадками, временем и ценой). Режим «Поехали»: подсказка сверху, голос, перестроение. Проложенный маршрут сохраняется и работает без сети; без маршрута — стрелка-компас |
| **Транспорт** | Метро Баку (линии, станции, маршрут между станциями), 249 автобусных маршрутов (OpenStreetMap), расписание поездов ADY (электрички, Газах, Габала, Тбилиси) с напоминанием в календарь телефона за 30 минут |
| **Цены на карте** | Вход в места, средний чек, ночь в отеле, проезд — в манатах и рядом в узбекских сумах по живому курсу. У известных мест — проверенная цена (зелёная), у остальных — примерная |
| **Офлайн-карты городов** | Векторная карта города (Protomaps, данные OSM): сервер вырезает её один раз (`server/pmtiles-extract.js`), телефон скачивает кусками с докачкой. Баку ≈ 11 МБ |

| **Ещё** | Чат между аккаунтами (постоянный ID), SOS, как платить картой BakıKart, поездки, города и места, погода и курс маната |

Данные:

### Мекка и Медина — помощник паломника

**Два приложения в одном.** Узбекистан — это `/` (index.html, js/app.js), Мекка и Медина — отдельное приложение `/mecca` (mecca.html, `js/mk-*.js`, `css/mecca.css`, данные `data/mk-*.js`). Они не загружают файлы друг друга, кроме общих готовых блоков (переводчик, SOS, документы, «Я потерялся») и общего стиля `css/style.css`, который Мекка только читает.

При первом открытии показывается приложение Узбекистана. Перейти в приложение Мекки и Медины или вернуться в Узбекистан можно только через аккаунт; выбранное направление хранится на устройстве (`safar_region`) и открывается напрямую при следующем запуске. Узбекская главная больше не показывает отдельный переход к старому разделу `#mecca`.

**Приложение `/mecca`** (зелёный с золотом, тот же стиль Safar), нижнее меню: Главная · Святыни · Отели · SOS · Еда · Карта · Поездка · Помощь.
- **Главная**: фото Мекки, поиск, следующий намаз, инструменты (SOS, «Я потерялся», переводчик, фразы, план поездки, намаз, мой отель, документы, медкарточка), главные святыни, города.
- **Святыни** (379): Масджид аль-Харам, Кааба, мечеть Пророка, Куба, Кыблатайн, Джабаль ан-Нур, Саур, Ухуд, Арафат, Мина, Муздалифа и др.; фильтры: мечети, святые места, музеи, история.
- **Отели** (815): сортировка «Ближе к Хараму» — расстояние до Харама или мечети Пророка, звёзды, имя, рядом со мной; кнопка Booking.
- **Еда и рынки** (1 312 + магазины), **Карта** со слоями (святыни, отели, еда), **город** — святыни и ближайшие отели.
- **Страница места**: фото, название по-арабски, маршрут, сохранить (`mk_favs`), позвонить, такси (Uber), «Показать таксисту» по-арабски и по-английски, описание из Википедии на языке приложения, мини-карта.
- **Поездка**: сохранённый на устройстве маршрут по местам Мекки и Медины, дата, число дней и путешественников. Встроенный расчёт расходов в саудовских риялах учитывает введённые пользователем стоимость номера, питание, местный транспорт и прочие расходы; это оценка, а не актуальные цены. Маршрут выбранных точек можно открыть в Google Картах.
- **Помощь** (`#mecca`): раздел помощника паломника (ниже).

Данные собирает `node scripts/fetch-mecca.mjs` (OpenStreetMap + Wikidata) → `data/mk-cities.js`, `data/mk-pois.js`, `data/mk-services.js`.

| Функция | Что делает |
|---|---|
| **Переводчик** (`#translate`) | Любые слова и фразы между узбекским, русским, английским, **арабским**, китайским, турецким, немецким, корейским и урду. Онлайн — бесплатный сервис MyMemory (до ~5 000 знаков в день с одного телефона). Голосовой ввод (микрофон) и озвучка перевода; «Показать собеседнику» — крупно на весь экран; «Ответ собеседника» — меняет языки, чтобы ответил араб. **Автоопределение языка**: если выбран не тот язык (написали по-узбекски, а выбран русский), приложение само его поменяет. **Без интернета**: 39 готовых фраз паломника (основное, «потерялся / отель», транспорт, здоровье, покупки, в мечети) на арабском с транскрипцией и озвучкой — проверены обратным переводом; всё, что человек уже переводил, сохраняется и открывается офлайн. Для любых слов офлайн — кнопка «Открыть в Google Переводчике» и инструкция, как заранее скачать офлайн-языки |

| **Время намаза** | Мекка и Медина, календарь Умм аль-Кура (Aladhan): фаджр, восход, зухр, аср, магриб, иша, хиджри-дата, следующий намаз выделен. Месяц сохраняется на телефоне — дальше без интернета |
| **Арабские цифры** | Таблица ٠–٩ и перевод номера ворот в обе стороны (79 ↔ ٧٩) |
| **SOS в Саудовской Аравии** | В разделе «Мекка» кнопки 911 (единый номер), 997 скорая, 999 полиция, 998 гражданская оборона; «Где я» показывает адрес и координаты без узбекских городов |
| **Документы и медкарточка** | Те же, что в Узбекистане (`#docs`), номера на карточке врача — саудовские |
| **Nusuk** | Ссылка на официальное приложение Саудовской Аравии (разрешения на умру и Рауду) |

Обряды умры и хаджа по шагам и дуа пока **не добавлены** намеренно: такие тексты должны проверить специалисты (например, Духовное управление мусульман Узбекистана).

**Живой голосовой перевод в Android APK:** при запуске приложения Safar автоматически начинает загружать арабскую и русскую модели перевода по Wi‑Fi; на первом запуске нужен интернет, а загрузку можно повторить с экрана переводчика. После загрузки текстовый перевод работает без сети. Кнопка «Офлайн-разговор» открывает экран, где арабская речь распознаётся локальным сервисом Android, а перевод на русский выполняется на телефоне. Для распознавания нужен Android 12+ и установленный на телефоне офлайн-пакет арабского языка. Поддержка проверяется при запуске; если её нет, приложение сообщит об этом и не переключится незаметно на отправку речи в интернет. После разговора последний перевод возвращается в Safar и сохраняется в истории.

**Офлайн-набор Мекки и Медины:** на главной нажмите «Скачать для офлайна» при подключении к сети. Safar сохранит каталог городов и мест, приложение и помощник паломника; затем поиск и карточки мест доступны без сети. Карта, её подложка и внешние сервисы по-прежнему требуют интернет или заранее доступный кэш.

### Аккаунты

- **Вход через Google** — кнопка «Продолжить с Google»: выбор аккаунта в один тап, без паролей и писем (Google Identity Services, бесплатно). Нужен `GOOGLE_CLIENT_ID` в `.env`. Сервер проверяет токен у Google: выдан для нашего Client ID, не просрочен, почта подтверждена. Почта наружу не отдаётся. В Telegram Mini App кнопка скрыта (там вход автоматический). Секрет клиента не нужен.
- **Вход через Telegram-бота**: «Войти через Telegram» → «Старт» в боте. Работает без домена и HTTPS.
- **Без входа работает всё** — об этом написано прямо под кнопками. Аккаунт нужен только для синхронизации между устройствами и отзывов.
- **Выход — с подтверждением** «Точно хотите выйти?» (кнопки «Остаться» / «Выйти»), чтобы случайное нажатие не выкидывало из аккаунта.
- **«Жалобы и предложения»** — заметной красной строкой в аккаунте, и без входа тоже.
  - На телефоне Telegram открывается сразу (ссылка `tg://`), без промежуточной вкладки браузера.
  - Когда человек возвращается в приложение, вход завершается сразу.
  - Бот присылает кнопку «Вернуться в Safar» — только на адрес этого же сайта (HTTPS).
- В **Telegram Mini App** вход происходит сам.
- Избранное и поездка синхронизируются между устройствами.
- Аккаунт можно удалить в самом приложении вместе со всеми данными.
- **В аккаунте всё «моё» сверху плитками** — «Мои билеты» (с числом), «Избранное», «Поездка», «Офлайн-города», «Паспорт», «Отображение»; видны и без входа. Ниже — разделы списком, все свёрнуты.
- Отменённые и отклонённые брони и заявки в аккаунте не показываются. Отклонённую анкету гида можно дополнить и отправить заново — она снова уходит на рассмотрение.

### Telegram-бот

- **`/start`** — приветствие и меню-кнопки прямо в нужные разделы: «Открыть Safar», «План поездки», «Поезда», «Цены на месте», «Безопасно ли?», «Разговорник», «Без интернета». Кнопки открывают Mini App, поэтому нужен HTTPS (`PUBLIC_URL`, или его сам задаёт `start.bat` с адресом ngrok). Без HTTPS остаётся только кнопка покупки билетов.
- **`/trains`** — время в пути между главными городами прямо в чате и кнопка uzrailpass.uz.
- **`/sos`** — экстренные номера прямо в чате, работает и без приложения.
- **`/city`** — «Город дня»: фото, область, население, сколько мест, отелей и кафе, кнопка «Открыть в Safar». Один город на весь день для всех.
- **`/word`** — «Слово дня» по-узбекски: та же фраза, что на главной приложения, с произношением.
- **`/remind`** / **`/remind_off`** — напоминания о поездке в чате: накануне в 19:00 и каждое утро в 8:00 по Ташкенту город дня и погода. Поездка берётся из аккаунта (синхронизация «Поездки»), поэтому нужно войти в Safar через Telegram (`server/botremind.js`).
- **`/stats`** — сводка статистики (только администраторам из `ADMIN_TG_IDS`).
- **`/help`**, **`/menu`**, **`/myid`**. Список команд в меню «/» показывается на языке пользователя (ru, uz, en).
- Короткие ссылки в приложение: `/?start=trains`, `safety`, `prices`, `offline`, `budget`, `map`, `favs`, `account`, а также `city_<id>`, `place_<id>`, `guide_<раздел>`.

### Гиды и экскурсии

1. Гид подаёт заявку в аккаунте («Кабинет гида»).
2. Администратор одобряет её.
3. Гид публикует экскурсии.
4. Турист бронирует экскурсию. Гиду приходит уведомление в Telegram, он подтверждает или отклоняет.

Оплата пока «гиду при встрече».

### Бизнес

1. Владелец нажимает «Это ваше заведение?» на странице места.
2. Администратор подтверждает.
3. Владелец правит описание, телефон, сайт, часы работы, цены и фото. Он отвечает на отзывы и видит статистику переходов.

Тариф «Партнёр» поднимает заведение выше в списках.

**Страница «Для бизнеса»** (`#partners`, ссылка в подвале главной): что даёт заведению Safar и тариф «Партнёр», кнопка «Оставить заявку в Telegram» (`/start biz` в боте). Администраторам из `ADMIN_TG_IDS` приходит уведомление с именем и @username — не чаще раза в сутки от одного человека.

**QR-постер** (`#poster`, для конкретного места — `#poster/<id>`): страница для печати на A4 с QR-кодом на Safar и подписями на 6 языках. Отель вешает его на ресепшене. QR рисует библиотека qrcode-generator (cdnjs), она грузится только на этой странице.

### Статистика и опрос (для теста на людях)

- **Анонимная статистика** (`server/stats.js`, `js/stats.js`): сколько людей заходит в день и сколько из них новых, какие разделы открывают, что делают (собрали поездку, добавили в избранное, построили маршрут, пригласили друзей, установили приложение…) и откуда пришли новые люди. Без IP, cookie и идентификаторов: «первый заход сегодня» и «первый заход вообще» отмечает само устройство, сервер хранит только счётчики по дням.
- **Откуда пришли** — метка `?from=` в ссылке. QR-постер места сам ставит `?from=poster_<id>`, поэтому видно, какой хостел или кафе приводит туристов. Свои метки можно ставить в любые ссылки: `https://адрес/?from=instagram`. Ссылки из бота считаются как «telegram», из друзей после опроса — «friend».
- **Опрос «Как вам Safar?»** — на третий день пользования, через 25 секунд, внизу экрана: 1–5 звёзд и «что улучшить» по желанию (текст — после согласия). «Не сейчас» — спросим через неделю, не больше двух раз. После 4–5 звёзд — кнопка «Отправить друзьям». Оценка 1–3 с комментарием сразу приходит администраторам в Telegram.
- **Где смотреть:** админка → вкладка «Статистика» (14 дней: по дням, источники, действия, разделы, оценки и комментарии), команда **`/stats`** в боте (только для `ADMIN_TG_IDS`) и **сводка каждый вечер в 21:00** по Ташкенту, если в этот день были заходы.

### Админка

Статистика, заявки гидов и заведений, модерация отзывов, сообщения об ошибках в данных мест (`#admin`). **По умолчанию выключена**: страница ведёт на главную, а `/api/admin/*` отвечает 404. Включается строкой `ADMIN_ENABLED=1` в `.env`.

### Поисковики

У каждого города и места есть своя страница с микроразметкой schema.org (`/city/samarkand`, `/place/n123`). Также сервер отдаёт `sitemap.xml` (~9 500 адресов) и `robots.txt`.

## Технологии

- **Интерфейс** — чистый JavaScript без фреймворков и сборки. Карта — [Leaflet](https://leafletjs.com). Иконки — SVG-спрайт ([Lucide](https://lucide.dev) и собственные). Шрифт — Montserrat.
- **Сервер** — Node.js без веб-фреймворков. База — встроенный SQLite (`node:sqlite`).
- **Зависимости** — только `@anthropic-ai/sdk` (ИИ-гид) и, для сборки APK, `@bubblewrap/core`.
- **Офлайн** — сервис-воркер (`sw.js`).
- **Push** — Web Push реализован без библиотек (RFC 8291 + VAPID).
- **Маршруты** — OSRM по данным OpenStreetMap.
- **Азербайджан** — офлайн-перевод [Bergamot](https://browser.mt) (Mozilla, `vendor/bergamot`), распознавание текста [Tesseract.js](https://tesseract.projectnaptha.com) (`vendor/tesseract`), векторные карты [protomaps-leaflet](https://github.com/protomaps/protomaps-leaflet) (`vendor/protomaps`). Всё лежит в проекте, чтобы работать без интернета.

## Запуск на своём компьютере без хостинга

1. Двойной щелчок по `start.bat`. Он поднимает туннель ngrok и сервер, перезапускает их при падении и пишет журналы в `storage/logs`.
2. Чтобы Safar запускался сам при входе в Windows, один раз запустите `autostart.bat`. Выключить: `autostart.bat off`.
3. Задайте в `.env` постоянный адрес `NGROK_DOMAIN` (бесплатно: кабинет ngrok → Domains). Тогда адрес не меняется после перезапуска, и APK не нужно пересобирать.

Компьютер при этом должен быть включён и не уходить в сон.

## Android-приложение (APK)

```bash
npm run android -- --url https://ваш-публичный-адрес
```

Команда собирает `android/safar.apk` через Google Bubblewrap (Trusted Web Activity): приложение открывает сайт во весь экран, без адресной строки.

- **Первый запуск** скачивает JDK 17 и Android SDK в `~/.bubblewrap` (~1,5 ГБ вместе с Gradle) и просит принять лицензию Android SDK.
- **Сервер должен работать**: манифест и иконки берутся с `http://localhost:PORT` (другой адрес — флаг `--local`).
- **После сборки** перезапустите сервер. На Android в «Установить приложение» появится кнопка «Скачать приложение» (`/download/safar.apk`) с инструкцией, как разрешить установку.
- **Адрес встраивается в APK навсегда.** Если адрес сменился, APK нужно пересобрать.
- **Ключ подписи** — `android/safar.keystore`, пароли — `android/signing.json`. Храните их отдельно и не теряйте: без того же ключа обновление не встанет поверх установленного приложения. В git они не попадают.

## Как устроен код

- **Модули сервера.** Каждый файл в `server/` экспортирует `routes = [[метод, путь, обработчик], …]` и, по желанию, `onStart()`. Новый модуль подключается одной строкой в списке `MODULES` в `server/index.js`.
- **Расширения интерфейса.** Файлы в `js/` подключаются к ядру через объект `EXT` в `app.js`: `EXT.routes`, `EXT.onInit`, `EXT.onLang`, `EXT.accountSections` и другие. Ядро про них не знает.
- **Переводы.** Строка — `key: [uz, ru, en]` в `i18n.js` и `key: [tr, de, zh, ko]` в `i18n-extra.js`. В коде — `t("key", { переменные })`.
- **Подтверждение действий.** `await askConfirm({ title, text, ok, cancel, danger })` в `js/app.js` — окно «Вы уверены?» в стиле приложения вместо системного `confirm()` (по умолчанию выбрана безопасная кнопка).
- **Смена темы.** `setTheme()` шлёт событие `safar:theme` — по нему перекрашивается то, что рисуется не через CSS (кнопка Google, окно Telegram). Цвета — только через переменные (`--card`, `--text`, `--glass`, `--field` …), тогда новая тема применяется сама.
- **Вход и выход.** После `signedIn()` / `signedOut()` вызывается `authChanged()`: аккаунт перерисовывается сразу, приходит событие `safar:auth`.
- **Иконки.** `icon("name")`. Добавить новую: впишите её в `scripts/build-icons.mjs` и запустите `node scripts/build-icons.mjs`.
- **Кэш.** При изменении файлов приложения поднимите `VERSION` в `sw.js`, иначе у пользователей останется старая версия.
- **Отладка заставки:** `/?splash&route=1&phase=day` — заставка не закрывается (`&short` — короткая версия).

## Как продолжать работу

**Добавить функцию в интерфейс**

1. Новый файл `js/моя-функция.js`. Подключитесь к ядру через `EXT`: `EXT.placeExtras.push(p => "html")` — блок на странице места, `EXT.routes.имя = fn` — свой адрес `#имя/…`, `EXT.onInit.push(fn)` — при запуске. Хорошие примеры: `js/crowd.js` (блок у места + сервер), `js/together.js` (вкладка «Поездка»).
2. Подключите файл строкой `<script defer src="js/…">` в `index.html` **и** добавьте его в список `SHELL` в `sw.js`.
3. Тексты — через `t("ключ")`, ключи добавьте в оба файла переводов.
4. Стили — в конец `css/style.css`. Цвета — только через переменные (`var(--text)`, `var(--muted)`, `var(--gold-ink)` …), тогда тёмная тема работает сама.
5. Поднимите `VERSION` в `sw.js`.

**Добавить адрес на сервере**

1. Новый файл `server/имя.js` с `module.exports = { routes }` (пример — `server/crowd.js`).
2. Таблица — `db.exec("CREATE TABLE IF NOT EXISTS …")` в начале файла.
3. Для записи: `readJSON(req, лимит)`, `rateLimiter(…)`, проверка входа `auth.userFrom(req)`.
4. Допишите модуль в `MODULES` в `server/index.js` и перезапустите сервер.

**Проверить перед выкладкой**

```bash
# синтаксис всех файлов
for f in js/*.js server/*.js; do node --check "$f"; done
```

```bash
# сервер на отдельной тестовой базе — рабочая storage/ не трогается
SAFAR_STORAGE=./test-storage PORT=3001 TELEGRAM_POLLING=0 node server.js
```

Затем откройте <http://localhost:3001> в браузере в режиме телефона (DevTools → 375 px), пройдите главную, город, место, «Поездку», аккаунт в светлой и тёмной теме и посмотрите консоль на ошибки. Папку `test-storage` потом можно удалить.

**Работа с ИИ-помощником.** Проект устроен так, что Claude Code или другой помощник быстро в нём разбирается: дайте ему прочитать этот README и `ROADMAP.md`. Попросите не трогать рабочий сервер и `storage/`, тестировать через `SAFAR_STORAGE` и проверять на ширине телефона.

## Конфиденциальность и безопасность

- **Согласие.** При первом открытии внизу появляется плашка о данных. Если её не трогать, через 20 секунд она исчезает сама. Это не считается согласием. Когда человек включает то, что требует данных (геолокация, вход, напоминания, отзыв, цена, сообщение об ошибке), по центру экрана появляется окно согласия. После «Принять» действие продолжается.
- **Документы.** Политика конфиденциальности и пользовательское соглашение доступны в приложении (`#privacy`, `#terms`) и по адресам `/privacy`, `/terms`.
- **Удаление аккаунта.** Аккаунт и все его данные удаляются в самом приложении.
- **Сервер** отдаёт наружу только файлы приложения: `.env`, `storage/` и исходники сервера недоступны.
- **Заголовки:** CSP `frame-ancestors` (встраивать можно только в Telegram), `Permissions-Policy`, `X-Content-Type-Options`, HSTS при HTTPS.
- **Ограничение частоты** запросов на вход, отзывы, цены, сообщения об ошибках, вопросы, обращения, отметки «Я здесь», общие поездки, статистику, опрос и ИИ. Размер тела каждого запроса ограничен.
- **Анонимность:** «Когда людно» хранит только час и день, а не человека (хеш IP со случайной солью меняется при каждом перезапуске). Статистика — только счётчики по дням, без IP и cookie. Фото в отзывах очищаются от GPS.
- **Секреты** (`.env`, ключ подписи APK, ключи push) в git не попадают — см. `.gitignore`.

## Состояние и резервные копии

- **`/health`** — состояние сервера для хостинга и мониторинга: работает ли база, сколько секунд сервер запущен, подключён ли бот, когда была последняя копия. Ответ 200, если всё в порядке, и 503, если база недоступна.
- **Резервная копия базы** делается сама раз в сутки (первая — через час после запуска) в `storage/backups/safar-ГГГГ-ММ-ДД.db`. Хранятся 7 последних. Копия целостная, даже во время работы (`VACUUM INTO`). Для восстановления остановите сервер и замените `storage/safar.db` нужной копией.

## Перед публичным запуском

1. **Хостинг с HTTPS** и домен. Укажите `PUBLIC_URL`; если сервер за прокси — `TRUST_PROXY=1`. SQLite нужен постоянный диск: бесплатные тарифы, которые стирают диск при перезапуске (Render free и т. п.), не подходят.
2. **Где хранить данные.** По закону Узбекистана персональные данные граждан Узбекистана должны храниться на серверах в Узбекистане. Если среди пользователей будут узбекистанцы — берите местный хостинг или уточните у юриста.
3. **Telegram.** Перевыпустите токен бота в @BotFather (`/revoke`), если он где-то светился. Для Mini App достаточно `PUBLIC_URL`.
4. **Карта.** Тайлы `tile.openstreetmap.org` подходят только для небольшой нагрузки. Подключите провайдера с ключом (MapTiler, Stadia) через `MAP_TILES` в `js/content.js`.
5. **Маршруты.** Серверы OSRM в проекте — демонстрационные. Для нагрузки нужен свой OSRM или платный API. Общественного транспорта и пробок нет: открытых данных по Узбекистану нет.
6. **Погода.** Бесплатный Open-Meteo — только для некоммерческого использования. Когда Safar начнёт зарабатывать — коммерческий тариф.
7. **Платежи.** Экскурсии и тариф «Партнёр» пока без онлайн-оплаты. Для Payme, Click или Uzum нужен договор мерчанта (ИП или ООО).
8. **Документы.** Заполните `OPERATOR` и `CONTACT`, покажите политику и соглашение юристу.
9. **Бэкапы.** Копия базы делается сама раз в сутки (`storage/backups`). Раз в неделю копируйте её ещё и с сервера к себе.
10. **APK.** После переезда на домен пересоберите APK (`npm run android -- --url https://домен`): адрес встроен в приложение.

## Запуск без денег и бюджет

*Цены примерные (октябрь 2026), проверяйте перед покупкой.*

**Этап 1 — 0 сумов.** Сервер на своём компьютере: `start.bat` + бесплатный постоянный адрес ngrok (`NGROK_DOMAIN`), `autostart.bat` — запуск при включении Windows. APK раздаётся с сайта и через бота, Google Play пока не нужен. Подходит для теста на 20–100 людях; компьютер должен быть включён.

**Этап 2 — продвижение почти бесплатно.**
- QR-постеры (`#poster`) — распечатать и отнести в хостелы и гостевые дома (~1–2 тыс. сум за лист).
- Telegram-группы путешественников, картинка «Дневника поездки» для Instagram, гиды (профиль в Safar для них бесплатный).
- Партнёрские ссылки (`ESIM_URL`, `INSURANCE_URL`, `BOOKING_AID`) — регистрация бесплатная, доход с первых пользователей.
- IT Park Uzbekistan, студенческие стартап-конкурсы и хакатоны — гранты, льготы, наставники.

**Этап 3 — свой сервер (~150–300 тыс. сум в месяц).**

| Что | Цена |
|---|---|
| VPS 2 ядра / 4 ГБ / 40+ ГБ (местный — UzCloud, Uztelecom, ahost.uz и др.; зарубежный — Hetzner, DigitalOcean) | ~5–10 $ или ~150–300 тыс. сум в месяц |
| Домен .uz (или .com) | ~100 тыс. сум в год (.com ~12 $) |
| HTTPS (Let's Encrypt) | бесплатно |
| Google Play | 25 $ один раз |

**Этап 4 — когда сотни пользователей в день (~50–80 $ в месяц):** свой сервер маршрутов OSRM (+4–8 ГБ памяти), платные тайлы карты (~25 $), коммерческая погода Open-Meteo (~30 €). По желанию: ИИ-гид (Claude API, ~10–50 $ при лимитах), App Store (99 $ в год).

**Правило:** первые деньги — на печать постеров и домен, не на рекламу. Живые отзывы первых туристов дают больше.
